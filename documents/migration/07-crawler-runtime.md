# 07 크롤러 실행 환경 확장

지금 크롤러 코드는 실행기가 가져온 페이지 하나나 앞 단계의 데이터를 받아 가공하는 것만 할 수 있다. 사용자가 크롤러만으로 외부 API를 부르고, 음성을 만들고, 결과를 자기 사이트에 게시하는 것까지 할 수 있게 실행 환경을 넓힌다.

## 외부 호출

- 크롤러 코드 안에서 HTTP 요청을 보낼 수 있다.
- 사설망·내부 주소로는 보낼 수 없다. 지금 URL을 가져올 때의 차단과 같다.
- web 크롤러의 지금 동작(실행기가 URL을 가져와 본문을 코드에 넘김)은 그대로다.

## 실행 시간과 코드 길이

- 외부 API 호출 몇 번(음성 합성 등)이 끝날 수 있을 만큼 실행 시간을 늘린다.
- 코드 길이 제한도 실제 작업이 들어갈 만큼 늘린다.
- 시간을 넘긴 실행은 지금처럼 실패로 기록한다.

## 큰 결과

- 크롤러가 파일(오디오, 이미지 같은 바이너리)을 결과로 남길 수 있다.
- 파일은 저장소에 두고, 결과에는 그 파일을 가리키는 참조가 들어간다. 다음 단계에는 이 참조가 넘어간다.
- 다음 단계의 크롤러는 참조로 파일을 읽을 수 있다.
- 파일은 그 크롤러를 실행한 사용자만 읽을 수 있다.
- 스케줄 회차에서 만든 파일은 그 회차 기록이 지워질 때 같이 지워진다.
- 직접 실행에서 만든 파일은 하루 뒤 지워진다.

## 환경 변수

- 사용자가 이름과 값을 등록한다. 사용자 단위이고, 그 사용자의 크롤러는 쓰겠다고 선언한 이름의 값만 받는다(2026-10-17 변경, 처음에는 모든 크롤러가 모든 값을 받았다).
- API로 등록, 이름 목록 조회, 값 변경, 삭제를 할 수 있다.
- 자기 크롤러를 실행할 때만 전달된다. 다른 사람이 만든 크롤러나 시스템 크롤러를 실행할 때는 전달되지 않는다. 그 크롤러 작성자가 외부 호출로 값을 가져갈 수 있기 때문이다. 스케줄 단계도 같다.
- 값은 암호화해 저장하고, 저장한 뒤에는 다시 보여 주지 않는다. 이름만 보인다.
- 크롤러 코드는 실행할 때 이름으로 값을 읽는다.
- 로그와 실행 결과에 값이 그대로 나오면 가린다.
- 크롤러를 다른 사람과 공유하거나 공개해도 환경 변수는 따라가지 않는다.
- 키를 코드에 직접 써 넣는 것은 막지 않는다.

## 실행 로그

- 크롤러 코드의 콘솔 출력과 오류가 실행 기록에 남는다. 크롤러를 직접 실행할 때와 스케줄 단계로 실행할 때 모두 해당한다.
- 로그는 크기 상한이 있고, 넘으면 잘라서 남긴다.
- 크롤러를 직접 실행하면 응답에 결과(파일이면 참조)와 로그가 같이 온다.

## 그대로인 것

- 기존 크롤러는 고치지 않아도 지금처럼 동작한다.
- 시스템 크롤러 5개도 그대로 동작한다.

## 이번에 하지 않는 것

- 사용량 제한(실행 횟수, 시간, 저장 용량, 외부 요청 수). 다음 단위에서 한다.
- 웹 화면(환경 변수 등록, 로그와 파일 보기). 웹 크롤러 화면 단위에서 한다.
