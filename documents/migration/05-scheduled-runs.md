# 05 스케줄 자동 실행

지금 스케줄러는 cron 식을 저장만 하고 실행하지 않는다. 저장된 스케줄이 그 시각에 자동으로 실행되게 한다.

## 실행

- 켜져 있고 cron 식이 있는 스케줄은 cron 식의 시각마다 파이프라인을 자동으로 실행한다.
- 10분마다 도는 cron trigger 하나가 실행할 시각이 된 스케줄을 찾는다.
- 회차 하나는 Cloudflare Workflow 인스턴스 하나로 실행한다.
- 같은 회차는 두 번 실행되지 않는다.
- 이전 회차가 아직 진행 중이면 이번 회차는 실행하지 않고, 건너뛴 것으로 기록한다.
- 놓친 회차는 보충하지 않는다. 여러 회차를 놓쳤어도 한 번만 실행한다.
- 실행이 도중에 중단되어 끝나지 않은 기록이 남아도, 그 때문에 이후 회차가 계속 건너뛰어지지 않는다.
- 스케줄을 끄거나 cron 식을 지우면 자동 실행이 멈춘다.
- 수동 실행(`POST /schedulers/:id/execute`)은 지금처럼 동작한다.

## 시각

- cron 식의 분은 10분 단위(0·10·20·30·40·50)만 저장할 수 있다. 다른 값은 거절한다.
- 스케줄마다 시간대가 있고, cron 식은 그 시간대로 해석한다. 기본값은 `Asia/Seoul`이다.
- 이미 저장된 스케줄도 10분 단위로 바꾼다. 분은 10분 단위로 내린다.

## 기록

- 실행 기록에서 예약 실행과 수동 실행이 구분된다.
- 예약 실행 기록에는 어느 회차(예정 시각)의 실행인지 남는다.
- 건너뛴 회차도 실행 기록에 남는다.

## 웹

- 사용자는 실행 시각을 10분 단위로만 고를 수 있다.
- 스케줄 화면에 시간대와 다음 실행 시각이 보인다.
- 실행 기록에 건너뛴 회차가 보인다.
